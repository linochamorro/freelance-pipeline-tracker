# Moneda fija: soles peruanos (PEN)

**Fecha:** 2026-11-14 · **Estado:** Aprobada

Todos los importes se expresan en soles peruanos. La interfaz muestra el símbolo literal `S/.` y no ofrece selector de moneda. Los valores numéricos se conservan tal como se guardan; no hay conversión de divisas.

La moneda no es una preferencia de usuario ni requiere un campo en `UserSettings` o una migración de base de datos. El formato localizado usa `es-PE` con el símbolo explícito `S/.`.
